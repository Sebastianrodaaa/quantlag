# UI reference pack (Sebastian's Pinterest board https://www.pinterest.com/roda0050/ui/)
Pins pin01-pin06.jpg (public feed, pulled 2026-11-02). Common style:
- Dark, near-black, mostly monochrome dashboards, with one restrained accent color.
- Dense pro-tool layout: left sidebar, panel grid, small mono labels, thin borders, rounded cards.
- Data viz front and center: 3D terrain/city maps, glowing node/graph networks, embedding-style cluster scatter plots, waveform/bar mini charts.
- Minimal typographic moments (big clean clock/number on light background).
Use this as the look for every project UI, dashboard, demo GIF/video and README visuals. Real data only.
